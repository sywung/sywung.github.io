# 教室座位抽籤

適合 72 吋 Android TV 瀏覽器與觸控螢幕使用的座位安排網頁。純前端、單人使用，不需要伺服器。

## 使用方式

直接用瀏覽器開啟 `index.html`。按座位表右上角「⚙」設定排數（直排數量，預設 7）與每排座位數（每排前後座位數，預設 6），可用兩種方式建立學生名單：

1. 「產生座號」：輸入開始號碼與學生人數，自動建立連續座號清單（無姓名）。
2. 「匯入學生名單」：在文字框貼上「座號 姓名」，一行一位（可用空白、逗號或 Tab 分隔），按「建立學生名單」即依座號排序建立名單；匯入會取代目前名單與座位安排。

建立名單後可在清單中移除不在班上的座號，再指定座號到座位，最後按「重新抽選」。指定座位會保留，其餘座位會重新亂數排列。座位上會顯示座號（第一行）與姓名（第二行，若有），皆置中對齊。

空位可透過「設定空位」模式點選；再次點選可取消空位。點擊已安排的座位可清除該座號。

已安排的座位可用滑鼠拖曳，或在觸控螢幕上按住後拖到另一個座位進行換位；指定座位與空位狀態會一併移動。

資料保存於目前瀏覽器的本機儲存空間，並保留最近 20 次產生日期。清除瀏覽器資料或更換瀏覽器後資料不會自動轉移；可用「本機保存紀錄」區的「匯出完整資料」／「匯入完整資料」搬移整包資料（排數、座位、名單、設定），或用「匯出文字檔」單純備份文字版座位表。

在「⚙ 座位設定」面板下方可填寫學校／學年度／學期／班級／導師，供列印時使用。按「列印／輸出 PDF」會開啟瀏覽器的列印預覽，選擇「另存為 PDF」即可輸出座位表 PDF（左側含座號＋姓名名單、座位格、置中講台標示、右下角紅字輸出日期）。

## 已知限制

- 姓名資料採手動貼上文字匯入，尚未支援 CSV／Excel 檔案匯入。
- 座位上的姓名以省略號處理過長內容，欄位極窄（例如 20 欄）時 4 個中文字仍可能被截斷。
- 歷史紀錄目前保存摘要與結果資料，但介面尚未提供點選歷史紀錄回復功能。
- Android TV 若使用遙控器操作，建議搭配滑鼠或觸控板完成設定。
- 觸控模式會放大輸入框、按鈕、座位與移除按鈕，並避免點擊時觸發頁面縮放。
- PDF 輸出未包含班級幹部（班長/學藝股長等）子表格；大班級接近或超過一頁時的分頁效果尚未實機驗證。
